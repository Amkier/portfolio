# 刘嘉成 · 工业设计作品集

React + Vite 单页网站，蓝白简洁风，封面式首屏排版，桌面版心最大 1700px，同时适配手机。

## 本地运行

已安装依赖时，在本目录运行：

```sh
pnpm dev --port 5173
```

浏览器打开 http://127.0.0.1:5173/ 。也可以双击 `启动预览.cmd`。首次在其他电脑运行时，请安装 Node.js 22+，再执行 `npm install` 和 `npm run dev`；本项目随附 pnpm 锁文件，优先使用 pnpm 保持依赖一致。

```sh
pnpm install
pnpm build
pnpm preview
```

构建产物位于 `dist/`，可部署到静态网站托管平台。本次仅提供本地预览，未公开发布。

## 页面与交互

- 全屏 Hero：本地循环背景视频、暂停/播放、锚点导航、联系入口。
- 关于我：从简历提取的人像、个人介绍、教育与实践经历、4 个作品集项目。
- 精选作品：4 个项目卡片及详情弹窗，支持 Escape 关闭和键盘操作。
- 个人优势：研究、CMF、结构原型、数字体验四类能力。
- 全屏联系页：邮件、电话、邮箱复制、返回顶部。
- 移动端菜单、减少动态效果偏好、视频静态封面降级。

## 素材说明

个人信息与人物照片来自用户提供的简历。人物照片按原始彩色展示，不使用灰度滤镜或混合模式。

四个精选项目按用户提供的 37 页《作品集.pdf》更新：

- 第 4–12 页：AMK 人体工学静音鼠标。
- 第 13–20 页：AMK 公共场所禁烟机器人。
- 第 21–29 页：便携式手语翻译设备。
- 第 30–36 页：宠物智能陪伴 App。

封面直接从作品集原页裁切，产品形态未被重新生成。详情中保留对应项目的全部设计过程原页，共 33 页，并提供新窗口查看原图入口。图片路径为 `public/projects/page-XX.jpg`。

Hero 使用用户提供的《7月29日.mp4》机器人视频（约 54 秒、1920×1080），静音自动循环播放；静态封面从原视频提取，位于 `public/projects/hero-robot.jpg`。首屏文字使用白色以适配视频背景，其余页面保持蓝白配色。

网页文字根据作品集整理，设计功能按方案意图表述，不将渲染图或研究页写成已验证的量产性能。

## 已验证

生产构建通过；1440px、1920px 桌面与 390px 手机视口无横向溢出；1920px 视口版心为 1700px；图片加载、视频播放/暂停、四个项目弹窗、Esc 关闭、手机导航、邮箱复制以及减少动态效果偏好通过浏览器检查，无 JavaScript 运行错误。
